# Deck style — single source of truth

Everything here is **frozen** so every card reads as one deck. The only things
that change per card are the **scene description** (Step 2) and the **seed**.
Do not edit this file to fix one card; edit it only to re-style the whole deck.

## Style block (prompt preamble)

Prepend this verbatim to every card's render prompt, then append the card's
scene description, then the frame-agnostic tail (below).

```
wdctarot. A hand-drawn illustration in the style of Pamela Colman Smith and early-twentieth-century esoteric book-plate art, rendered as a bold woodcut / linocut print: heavy black ink outlines on every form, dense cross-hatching and hatched shading, high tonal contrast, strong graphic linework, flat screen-printed color fills, and an aged-paper grain. Muted earthy palette: slate blue-grey, ochre and umber, sage green, aged cream. Symbolic, archetypal, calm and reverent storybook mood. A single full-bleed scene that fills the whole image, flat 2D illustration, no photorealism, no 3D render, no modern objects.
```

Do not add a gold-accent phrase back. "with a single warm gold accent on the
focal symbol" was cut on 2026-10-09: in a same-seed A/B (8 scenes × 3 seeds) it put a stray
gold badge, glyph or floating shape in 10 of 24 renders and none without it; palette and
atmosphere were unchanged. Gold that a card needs goes in its scene text. Renders from before
the cut replay their recorded prompt (`render_card.py --from-card`), so existing cards are unaffected.

## Frame-agnostic tail (prompt suffix)

`frame_card.py` draws the border, banner, and title. The model must NOT draw
them, or you get a double border and garbled text. End every render prompt with:

```
Composition fills the whole frame. No text, no lettering, no title, no border, no banner, no card frame, no signature, no page numbers.
```

Leave the bottom ~12% of the scene free of critical detail — the frame's title
banner sits there.

## Render parameters (frozen)

Baked into `assets/tarot-card-flux.json`; listed here as the contract.

| Param | Value |
|---|---|
| checkpoint | `flux1-dev-fp8.safetensors` |
| base size | 896 × 1536 |
| sampler / scheduler | euler / simple |
| steps | 20 |
| guidance (FluxGuidance) | 3.5 |
| cfg (KSampler) | 1.0 |
| upscale | 4x-UltraSharp → ImageScale 1024 × 1792 (center) |
| seed | **per card** — recorded in the card file (`seed` and `## Render Record`) |

## Frame flags (frozen)

```
--art-crop 0.035   # trims FLUX's own inner border
--paper 216,199,158
--ink 26,22,18
--margin-frac 0.020
--border-frac 0.008
--banner-frac 0.085
# font: default serif auto-pick (LiberationSerif-Bold)
```

## Maximum-fidelity option (later)

Prompt-only style is *recognizably* one deck but linework/palette still wobble
per card. For published-deck tightness, train a **style LoRA** on the reference
samples + best generated cards (~20–40 images), drop it in `models/loras/`, and
add a `LoraLoader` between the checkpoint and the sampler in the workflow. Not
required to start.
